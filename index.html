tokenization challenge

A scanner reads source code and cuts it into lexemes. Your job is to name the token type of each highlighted lexeme. Pick a level to start.

Game rules

  1. Choose a difficulty level. Each level has 3 code snippets and asks 4 questions per snippet, so 12 questions in total.
  2. One lexeme in the snippet is highlighted. Choose the token type that the scanner would assign to it.
  3. You get instant feedback and a short reason after every answer. One answer per question, no undo.
  4. The questions are drawn at random each game, so replaying a level gives new targets.
  5. After question 12 you see your score, rating and a review of every mistake.

Scoring

  • Correct answer: the points for your level.
  • Streak bonus: from your 3rd correct answer in a row, each further correct answer adds +5.
  • Wrong answer: loses the level's penalty and resets your streak. Your score never drops below 0.
  • Maximum score: Easy 170, Medium 230, Hard 290 (every answer correct, streak bonus included).

Token types

Scanner rules to remember

  • Longest match: >= is one operator, not > then =.
  • Keywords beat identifiers: int is a keyword, but intValue is an identifier.
  • Quotes and comments swallow everything inside them. A keyword inside a string is still part of the string.
  • Whitespace separates lexemes but is never a token.

Keyboard: press 1 to 7 to choose an answer. Press Enter on the Next button to continue.
